# 🔴 YOUTUBE PRO (KOTLIN) 🔴

Selamat datang di **YouTube Pro**, sebuah mahakarya aplikasi pemutar media tanpa batas! Dirancang khusus untuk memberikan pengalaman menonton dan mendengarkan YouTube yang bersih, super ringan, dan pastinya bebas hambatan.

---

## ✨ Fitur Unggulan (Sultan Features)
*   🎧 **Background Playback:** Audio tetap menyala mulus meski layar HP dimatikan atau saat berpindah aplikasi (Anti *Krek-Krek* Club!).
*   🚫 **AdBlock Super:** Menonton tenang tanpa interupsi iklan banner, promo *sign-in*, maupun video *pop-up*.
*   🌙 **Pure Dark Mode:** Tampilan gelap pekat 100% yang elegan dan sangat ramah di mata.
*   🧹 **Auto Deep Cleaner:** Membakar ampas *cache* secara otomatis setiap kali aplikasi ditutup agar memori HP tetap lega.
*   ⚡ **Smooth Navigation:** Tombol *back* dan navigasi ke Beranda yang sudah dimodifikasi agar senatural aplikasi bawaan (Navigasi Anti-Nyangkut).
*   📱 **Adaptive Fullscreen:** Deteksi orientasi otomatis menggunakan injeksi JavaScript canggih untuk menyesuaikan rasio video (Landscape/Portrait) secara *immersive*.
